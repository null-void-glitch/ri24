Voraussetzungen & Google Cloud Setup

Die Google Maps Embed API ist kostenpflichtig, hat aber ein großzügiges Freikontingent (Stand 2026: 28.000 Aufrufe/Monat kostenlos).

  1. Google Cloud Console öffnen: console.cloud.google.com
  2. Projekt anlegen oder bestehendes auswählen
  3. Rechnungskonto verknüpfen (Pflicht – sonst werden alle API-Anfragen abgelehnt)
  4. Maps Embed API aktivieren: APIs & Dienste → Bibliothek → „Maps Embed API" suchen → Aktivieren
  5. API-Key erstellen: APIs & Dienste → Anmeldedaten → „+ Anmeldedaten erstellen" → API-Schlüssel
  6. Key einschränken (siehe Abschnitt 7)
⚠️
Ohne aktiviertes Rechnungskonto liefert die API HTTP 403 „The provided API key is invalid" — auch wenn der Key syntaktisch korrekt ist.

URL-Aufbau der Embed-API

Die Embed API kennt mehrere Modi. Für diesen Use-Case werden zwei davon verwendet:

Karten-Modus (place)

https://www.google.com/maps/embed/v1/place
  ?key=DEIN_API_KEY
  &q=Straße+1,+12345+Stadt,+Deutschland   ← URL-kodierte Adresse
  &zoom=16                                ← Zoomstufe 0–21 (16 = Straße)

Street-View-Modus (streetview)

https://www.google.com/maps/embed/v1/streetview
  ?key=DEIN_API_KEY
  &location=50.495488,12.127437           ← Breitengrad,Längengrad
  &heading=180                            ← Blickrichtung in Grad (0 = Nord, 180 = Süd)
  &pitch=0                               ← Neigung -90 (Boden) bis +90 (Himmel)
  &fov=90                                ← Sichtfeld 10–100 (Standard 90)
ParameterPflicht/OptionalBeschreibung
keyPflichtDein Google Maps API-Key
locationPflicht (SV)Koordinaten als lat,lng
headingOptionalKompassrichtung der Kamera (0–360). Wichtig: auf Hausfassade ausrichten
pitchOptionalVertikale Kameraneigung (-90 bis +90)
fovOptionalSichtfeldwinkel in Grad (Standard 90)
qPflicht (place)Suchanfrage oder Adresse für Kartenmodus
zoomOptionalZoomstufe 0–21 (Standard ~15)
💡
Den optimalen heading-Wert ermitteln: Google Maps in der Browser-URL aufrufen und die Kamera manuell auf die Fassade richten. Der Wert steht in der URL hinter @lat,lng,....

HTML-Struktur

Der Block besteht aus einer Tab-Leiste und zwei <iframe>-Containern. Der Street-View-iframe bekommt zunächst kein src — er erhält es erst beim ersten Tab-Klick (Lazy-Load, spart API-Kontingent).

<!-- Karte + Street View – Tab-Block -->
<div class="map-tabs">

  <!-- Tab-Leiste -->
  <div class="map-tab-bar" role="tablist">
    <button class="map-tab active"
            role="tab" aria-selected="true"
            data-tab="map">🗺 Karte</button>
    <button class="map-tab"
            role="tab" aria-selected="false"
            data-tab="streetview">📷 Street View</button>
  </div>

  <!-- Iframe-Container -->
  <div class="map-frame-wrap">

    <!-- Tab 1: Karte (lädt sofort) -->
    <div class="map-tab-pane" id="tab-map">
      <iframe
        loading="lazy"
        allowfullscreen
        referrerpolicy="no-referrer-when-downgrade"
        src="https://www.google.com/maps/embed/v1/place
             ?key=DEIN_API_KEY
             &q=Musterstraße+1,+12345+Musterstadt,+Deutschland
             &zoom=16"
        title="Karte – Lage der Immobilie">
      </iframe>
    </div>

    <!-- Tab 2: Street View (Lazy: src wird per JS gesetzt) -->
    <div class="map-tab-pane" id="tab-streetview" hidden>
      <iframe
        id="sv-iframe"
        loading="lazy"
        allowfullscreen
        referrerpolicy="no-referrer-when-downgrade"
        data-src="https://www.google.com/maps/embed/v1/streetview
                  ?key=DEIN_API_KEY
                  &location=50.495488,12.127437
                  &heading=180
                  &pitch=0
                  &fov=90"
        title="Street View – Lage der Immobilie">
      </iframe>
    </div>

  </div>

  <!-- Pflichtangabe unter der Karte -->
  <p class="map-api-note">Kartenansicht powered by Google Maps</p>

</div>
✅
referrerpolicy="no-referrer-when-downgrade" stellt sicher, dass der Browser den korrekten Referer-Header an Google sendet. Ohne diesen Header lehnt die Embed API (seit Juli 2026) alle Anfragen mit HTTP 403 ab.

JavaScript – Tab-Logik + Lazy-Load

Kein Framework nötig – reines Vanilla JS. Das Snippet in ein <script>-Tag am Ende des <body> oder in eine externe JS-Datei einfügen.

(function () {
  var svLoaded = false;  // verhindert doppeltes Laden des Street-View-Iframes

  document.querySelectorAll('.map-tab').forEach(function (tab) {
    tab.addEventListener('click', function () {
      var target = tab.dataset.tab;

      // Alle Tabs deaktivieren
      document.querySelectorAll('.map-tab').forEach(function (t) {
        t.classList.remove('active');
        t.setAttribute('aria-selected', 'false');
      });

      // Angeklickten Tab aktivieren
      tab.classList.add('active');
      tab.setAttribute('aria-selected', 'true');

      // Panes ein-/ausblenden
      document.getElementById('tab-map').hidden        = (target !== 'map');
      document.getElementById('tab-streetview').hidden = (target !== 'streetview');

      // Street-View-Iframe: src erst beim ersten Öffnen setzen (Lazy-Load)
      if (target === 'streetview' && !svLoaded) {
        var iframe = document.getElementById('sv-iframe');
        iframe.src = iframe.dataset.src;
        svLoaded = true;
      }
    });
  });
})();
💡
Mehrere Expose-Seiten im SPA/React: Beim Rendern einer neuen Expose-Seite muss svLoaded auf false zurückgesetzt und das src-Attribut des Iframes geleert werden, damit der neue Street-View-Inhalt korrekt lädt.

Backend-Integration (dynamische Koordinaten)

Die Koordinaten und Adresse pro Immobilie kommen aus der Datenbank. Die URLs werden serverseitig in das Template gerendert.

Datenbankfelder (Empfehlung)

FeldBeispielwert
latPflicht50.495488
lngPflicht12.127437
map_headingOptional180 (Richtung auf Fassade)
streetPflichtNeundorfer Str. 47
zipPflicht08523
cityPflichtPlauen

PHP-Template-Beispiel

<?php
// Koordinaten und Adresse aus DB
$lat     = htmlspecialchars($expose['lat']);
$lng     = htmlspecialchars($expose['lng']);
$heading = (int)($expose['map_heading'] ?? 180);
$address = urlencode($expose['street'] . ', ' . $expose['zip'] . ' ' . $expose['city'] . ', Deutschland');
$apiKey  = GOOGLE_MAPS_API_KEY; // aus Konfigurationsdatei / .env
?>

<iframe
  loading="lazy"
  allowfullscreen
  referrerpolicy="no-referrer-when-downgrade"
  src="https://www.google.com/maps/embed/v1/place?key=<?= $apiKey ?>&q=<?= $address ?>&zoom=16"
  title="Karte – Lage der Immobilie">
</iframe>

<iframe
  id="sv-iframe"
  loading="lazy"
  allowfullscreen
  referrerpolicy="no-referrer-when-downgrade"
  data-src="https://www.google.com/maps/embed/v1/streetview
            ?key=<?= $apiKey ?>
            &location=<?= $lat ?>,<?= $lng ?>
            &heading=<?= $heading ?>
            &pitch=0&fov=90"
  title="Street View – Lage der Immobilie">
</iframe>

Twig / Django / Jinja2

<!-- Street View data-src (Twig / Jinja2) -->
data-src="https://www.google.com/maps/embed/v1/streetview
  ?key={{ google_maps_key }}
  &location={{ expose.lat }},{{ expose.lng }}
  &heading={{ expose.map_heading | default(180) }}
  &pitch=0&fov=90"
⚠️
Den API-Key niemals direkt in den Quellcode committen. Immer aus Umgebungsvariablen (.env) oder einem Secret-Manager lesen.

API-Key absichern

Ein nicht eingeschränkter API-Key kann von jedem Dritten missbraucht werden. In der Google Cloud Console folgendes einstellen:

Anwendungsbeschränkungen (HTTP-Referrer)

Unter APIs & Dienste → Anmeldedaten → Key → Anwendungsbeschränkungen → HTTP-Referrer die eigenen Domains eintragen:

https://www.regionalimmobilien24.de/*
https://regionalimmobilien24.de/*
http://localhost:8080/*          ← nur für lokale Entwicklung, danach entfernen

API-Einschränkungen

Unter API-Einschränkungen → Schlüssel einschränken nur die benötigte API auswählen:

  • ✅ Maps Embed API
  • ❌ alle anderen APIs deaktiviert lassen
✅
Nach dem Speichern der Einschränkungen dauert es ca. 5 Minuten bis die neuen Regeln aktiv sind.

Budget-Alert einrichten

Unter Abrechnung → Budgets & Benachrichtigungen ein monatliches Budget setzen (z. B. 10 €), um unerwartete Kosten durch Missbrauch zu erkennen.

Deployment-Checkliste

  • Maps Embed API im Google Cloud Projekt aktiviert
  • Rechnungskonto mit dem Projekt verknüpft
  • API-Key auf Produktions-Domain(s) eingeschränkt
  • API-Key nur auf Maps Embed API eingeschränkt
  • API-Key aus Code-Repository ferngehalten (nur in .env / Secret Manager)
  • Budget-Alert konfiguriert
  • Koordinaten + heading pro Immobilie in DB gepflegt
  • referrerpolicy="no-referrer-when-downgrade" auf allen iframes gesetzt
  • localhost-Referrer aus Key-Beschränkungen entfernt
  • Prototyp-HTML durch produktives Template ersetzt
