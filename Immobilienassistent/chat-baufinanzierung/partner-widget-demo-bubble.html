💬 RI24 Partner-Widget – lokale Demo (Bubble)

Simuliert, wie das Widget auf einer externen Berater-Seite aussieht — Floating-Launcher unten rechts. Der eigentliche Chat-Button erscheint erst, sobald DeepChat vom CDN geladen wurde (Internetzugriff nötig) und der lokale Proxy erreichbar ist.

Wichtig: diese Datei über http:// öffnen, nicht per Doppelklick als file:// — Browser blockieren das Nachladen von type="module"-Skripten (DeepChat-Bundle) über file:// per CORS-Policy, das Widget bliebe sonst dauerhaft unsichtbar.

  1. cd chat-baufinanzierung && php -S localhost:8001
  2. http://localhost:8001/partner-widget-demo-bubble.html öffnen
  3. Unten rechts auf den grünen Button klicken, um den Chat zu öffnen

Die echten Kopiervorlagen für Partner-Seiten (partner-widget-snippet-bubble-*.example.html) zeigen fest auf die Produktions-URL — hier überschreiben wir endpoint/resolveEndpoint auf den lokalen Server.
